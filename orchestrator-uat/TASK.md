# UAT task

1. Create the file `uat-report.txt` in the workspace containing exactly two lines:
   first line: `opencode-agent-smoke-uat`
   second line: the current date in YYYY-MM-DD format.
2. Write the structured result file at the path given by the AGENT_SMOKE_RESULT_PATH
   environment variable with the run id from AGENT_SMOKE_RUN_ID and
   `artifacts: ["uat-report.txt"]`.

Do not modify TASK.md or any other existing file.
